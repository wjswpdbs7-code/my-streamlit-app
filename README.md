# 에이블 · 2일차 통합 AI 비서

## 실행과 배포
1. Python 3.11 또는 3.12 환경에서 `pip install -r requirements.txt` 실행.
2. `secrets.example.toml` 내용을 참고해 `.streamlit/secrets.toml` 또는 환경 변수 설정.
3. 로컬: `streamlit run app.py`.
4. GitHub 저장소 루트에 app.py, requirements.txt, packages.txt, .gitignore 업로드.
5. Streamlit Community Cloud에서 저장소·브랜치·app.py 선택, Python 3.11 설정.
6. Cloud Secrets에 실제 API 키와 이메일 정보 입력. GH_TOKEN은 앱에 필요하지 않음.
7. TXT 첨부 → 질문 → 업무 근거 → 후속 질문 → 파일 다운로드 → 요청 시 메일 순서로 검증.

## 구조
모든 실행 코드는 app.py 하나에 통합되어 있으며 다른 Python 파일을 요구하지 않습니다.
수정 노트북의 원본 Markdown은 내용과 순서를 그대로 유지했습니다. 원본과 달라진 내용은 추가 설명 셀에서 안내합니다.
노트북에서 app.py 셀을 고친 경우 반드시 해당 셀을 다시 실행한 다음 push 셀을 실행하세요.
app.py를 직접 고친 경우 노트북의 이전 생성 셀을 실행하면 덮어쓰므로 편집 위치를 하나로 정하세요.
배포 ZIP은 키와 개인 자료를 포함하지 않습니다. 노트북은 실행 결과를 제거한 상태입니다.

## 기능
- 선택적 다중 첨부, 텍스트·음성 요청, 후속 대화(최근 5쌍).
- 이미지/PDF/CSV/XLSX/PPTX/DOCX/텍스트/STT 분석.
- 내 업무, 중간·최종 기한, 원문 근거 검증, 변경 비교, 상태 수정.
- TXT/MD/JSON/CSV/XLSX/DOCX/PDF/PPTX/PNG/MP3 결과 생성·다운로드.
- 번역·비즈니스 문장·영어 학습은 같은 입력창에서 요청.
- 현재 요청에 명시된 이메일만 설정된 수신자로 전송. 원본은 명시한 경우만 첨부.
- 화면 재실행/다운로드로 API·메일 재실행 안 함. 같은 입력은 재실행 선택 필요.

## 기록과 제한
- 업무는 세션 메모리에 유지. 재접속/서버 재시작 대비 업무 JSON 백업·복원 제공.
  여러 사용자 공유 DB, 예약 실행, 자동 알림, 로그인 기능은 포함하지 않음.
- 소유 세션별 임시 폴더를 사용하며 서버 파일을 영구 저장소로 사용하지 않음.
- 10개/개별20MB/합계25MB, 텍스트 개별12만/합계18만자, 이미지30장, 출력8개.
- 한글 PDF는 packages.txt의 fonts-nanum 사용. DOCX/PPTX는 텍스트 중심.
- 문서 근거는 공백 제외 문자열 일치로 검사. 의미의 타당성까지 보증하지 않음.
  스캔 PDF·이미지처럼 검증용 원문이 없는 업무는 자동 저장 보류, 답변으로 확인.
- 새 회의에 빠진 업무는 삭제하지 않음. 상태 변경은 사용자 요청/업무 화면에서 처리.
- CSV/Excel은 기초 통계만 Python 계산. 자유로운 분석 코드 실행이나 웹 검색은 미지원.
- 음성 출력은 선택 사항이며 AI 음성임을 표시. 인명·날짜 인식은 원문과 확인.
- API 사용 권한과 모델 수명은 계정에서 확인. 모델 ID는 Secrets/사이드바에서 변경 가능.
  기본 TTS/이미지는 1일차 모델 유지. 사용 불가 시 해당 생성만 실패하고 텍스트 유지.
- 이메일 의도 판정은 모델 기반으로 오판 가능. 배포 전 금지/초안/실제 요청 구분 테스트 필요.
  전송 결과가 불명확하면 자동 재시도하지 않으며 수신함을 확인해야 함.
- 실제 API/SMTP 테스트는 본 수정 작업에서 수행하지 않았습니다.

## 권장 점검
파일 없는 질문, 파일 업로드 후 질문, 기한 미정, 동명이인, 변경 회의, 업무 완료 후 후속 질문,
요약만/이메일 금지/명시적 발송, 다운로드 후 중복 발송 없음, 백업·복원, 각 파일 형식 다운로드.
